# Packager une application avec Helm

## 1. Introduction
Transformons notre déploiement précédent en chart Helm pour en faciliter la gestion.

## 2. Le projet
1. Utilise `helm create` pour générer un nouveau chart.
2. Déplace les manifestes créés lors du jour précédent dans ce chart.
3. Personnalise `values.yaml` pour rendre l'image, le nombre de réplicas et le port configurables.

## 3. Rendu attendu
Le chart complet prêt à être installé avec `helm install`.

4. Partage ton travail sur GitHub avec un bref mode d'emploi.
