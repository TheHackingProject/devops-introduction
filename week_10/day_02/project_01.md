# Déployer un pod simple

## 1. Introduction
Appliquons la théorie en créant un premier pod sur Minikube.

## 2. Le projet
1. Installe Minikube et démarre un cluster local.
2. Écris un manifeste YAML décrivant un pod avec un conteneur Nginx.
3. Lance `kubectl apply -f` sur ton fichier et vérifie que le pod est `Running`.

## 3. Rendu attendu
Le fichier YAML et les commandes pour créer et vérifier le pod.

4. Partage ton travail sur GitHub avec un bref mode d'emploi.
