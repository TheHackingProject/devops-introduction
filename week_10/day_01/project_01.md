# Construire une image optimisée

## 1. Introduction
Tu vas créer un Dockerfile multi-stage pour builder et exécuter une application
simple.

## 2. Le projet
1. Prends une petite application (par exemple un serveur Node.js).
2. Écris un Dockerfile multi-stage où la première étape compile l'application.
3. Pousse l'image finale dans un registre privé ou sur Docker Hub.

## 3. Rendu attendu
Le Dockerfile et la commande pour construire/pousser l'image.

4. Partage ton travail sur GitHub avec un bref mode d'emploi.
