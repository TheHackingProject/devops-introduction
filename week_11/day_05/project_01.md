# Créer un bot simple

## 1. Introduction
Pour clôturer la semaine, nous allons mettre en place un bot capable de lancer un
script depuis Slack.

## 2. Le projet
1. Choisis un framework de bot (par exemple python-slack-sdk).
2. Programme une commande `/deploy` qui exécute un script de déploiement déjà
   existant.
3. Restreins l'usage de cette commande à un canal ou à un groupe d'utilisateurs.

## 3. Rendu attendu
Le code du bot et un court guide pour l'installer dans un espace de chat.

4. Partage ton travail sur GitHub avec un bref mode d'emploi.
