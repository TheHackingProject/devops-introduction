# Pipeline optimisé

## 1. Introduction
Nous allons créer un pipeline de test rapide grâce à la parallélisation et au cache.

## 2. Le projet
1. Mets en place un pipeline exécutant les tests unitaires en parallèle sur
   plusieurs versions de l'interpréteur ou de l'environnement.
2. Utilise un cache pour les dépendances et sauvegarde les rapports de tests
   comme artifacts.

## 3. Rendu attendu
Le fichier de pipeline ainsi qu'un bref compte rendu sur le temps gagné.

4. Partage ton travail sur GitHub avec un bref mode d'emploi.
