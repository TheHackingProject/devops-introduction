# Initialisation de l'infrastructure

## 1. Introduction
Déploie l'infrastructure minimale et mets en place la CI du projet.

## 2. Le projet
1. Crée les premières ressources (VM ou cluster, base de données).
2. Configure un pipeline qui teste et construit l'application à chaque commit.
3. Stocke les secrets nécessaires dans un gestionnaire sécurisé.

## 3. Rendu attendu
Les fichiers Terraform ou équivalents et la configuration du pipeline initial.

4. Partage ton travail sur GitHub avec un bref mode d'emploi.
