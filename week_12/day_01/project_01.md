# Préparation du dépôt

## 1. Introduction
Nous allons initialiser le projet final et créer la base du dépôt.

## 2. Le projet
1. Crée le dépôt Git et ajoute-y un fichier `README.md` décrivant rapidement ton
   objectif.
2. Mets en place une première structure de dossiers (`infra/`, `app/`, etc.).
3. Ouvre un tableau de suivi (GitHub Projects, Trello...) pour planifier la suite.

## 3. Rendu attendu
Le lien vers le dépôt initialisé et une capture du tableau de suivi.

4. Partage ton travail sur GitHub avec un bref mode d'emploi.
