# Collecte de premières métriques

## 1. Introduction
Avant de mettre en place des outils complexes, commence par récupérer quelques
informations système.

## 2. Le projet
1. Installe un petit exporter comme `node_exporter` ou écris un script qui envoie
   l'utilisation CPU dans un fichier.
2. Stocke ces valeurs régulièrement puis affiche-les sous forme de graphique
   simple (par exemple via `gnuplot`).

## 3. Rendu attendu
Un dossier contenant ton script ou l'outil utilisé et le graphique généré à
partir des données collectées.
4. Partage ton travail sur GitHub avec un bref mode d'emploi.

### Pour aller plus loin
Teste l'installation d'un serveur Prometheus local pour stocker tes métriques de manière durable.
