# Scanner une image Docker

## 1. Introduction
Nous allons vérifier qu'une image ne contient pas de vulnérabilités connues.

## 2. Le projet
1. Choisis une image publique sur Docker Hub.
2. Lance un scan avec Trivy et analyse le rapport généré.
3. Corrige ou signale au moins une vulnérabilité trouvée (par exemple en mettant
   à jour l'image ou un paquet).

## 3. Rendu attendu
Le fichier de rapport et une courte note expliquant la correction appliquée.

4. Partage ton travail sur GitHub avec un bref mode d'emploi.
