# Mettre en place un pare-feu

## 1. Introduction
Tu vas configurer un pare-feu simple pour filtrer l'accès à une machine.

## 2. Le projet
1. Utilise `ufw` ou `firewalld` pour autoriser uniquement le port SSH et celui de
   ton application.
2. Teste l'accès depuis une autre machine et vérifie que les ports non autorisés
   sont bien bloqués.

## 3. Rendu attendu
Un court tutoriel décrivant la configuration appliquée et les commandes de test
utilisées.

4. Partage ton travail sur GitHub avec un bref mode d'emploi.
