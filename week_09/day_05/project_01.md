# Pipeline de sécurité

## 1. Introduction
Pour finir cette semaine, ajoute un job de scan à un pipeline CI existant.

## 2. Le projet
1. Choisis un outil de SAST ou DAST compatible avec ton langage.
2. Crée un job dans la CI qui exécute ce scan et stocke le rapport en artefact.
3. Fails le build si une vulnérabilité critique est trouvée.

## 3. Rendu attendu
Le fichier de pipeline modifié et un exemple de rapport généré lors d'un scan.

4. Partage ton travail sur GitHub avec un bref mode d'emploi.
