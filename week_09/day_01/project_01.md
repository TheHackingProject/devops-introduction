# Analyser un dépôt

## 1. Introduction
Pour commencer doucement, tu vas passer un projet existant au crible des outils
d'analyse statique.

## 2. Le projet
1. Choisis une petite application open source.
2. Lance un scan avec SonarQube ou un outil équivalent pour lister les
   vulnérabilités détectées.
3. Classe les alertes par ordre de priorité et propose des pistes de correction.

## 3. Rendu attendu
Un rapport succinct contenant les principaux problèmes trouvés et tes conseils
pour les corriger.

4. Partage ton travail sur GitHub avec un bref mode d'emploi.
